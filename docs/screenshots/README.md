# 공개용 사용 화면

이 폴더의 JPEG는 실제 Art Style 프론트엔드를 공개용 샘플 데이터로 실행한 뒤 캡처한 화면입니다. 실제 계정이나 운영 서버의 데이터는 불러오지 않았습니다.

- 작업실 아이디는 `비공개`, 계정 이메일은 `u***@example.com`, 기기 코드는 `••••-••••`로 대체했습니다. 실제 기기 인증을 시작하거나 유효한 코드를 저장하지 않았습니다.
- 그림은 문서용으로 만든 단순 도형 샘플이며, 개인 라이브러리·사용자 업로드·외부 작가의 작업물을 사용하지 않았습니다.
- 프롬프트와 모델 목록도 사용법을 보여 주는 예시입니다. 화면은 분석 품질 평가 결과나 실제 연결 성공의 증빙으로 제공하는 것이 아닙니다.
- 주소창·브라우저 프로필을 포함하지 않았고, 캡처 파일에 EXIF나 개인 정보가 담긴 메타데이터가 없는지 확인했습니다. 픽셀을 편집한 이미지가 아닌, 개인정보를 대체한 화면의 캡처 원본입니다.

| 파일 | 보여 주는 내용 |
| --- | --- |
| `library-detail.jpg` | 저장한 이미지와 화풍·캐릭터 탭, 복사·다운로드 |
| `new-analysis.jpg` | 여러 장 선택, 기준 이미지, 분석 범위 |
| `codex-login.jpg` | 기기 코드 인증 단계와 가림 처리한 코드 |
| `codex-settings.jpg` | 가림 처리한 이메일, 모델·추론 정도·언어 설정 |
| `external-request.jpg` | 이미지 별도 첨부 방식의 JSON 요청문 |
| `json-import.jpg` | 외부 응답 확인과 이미지·JSON 저장 |

공개 파일 검사 도구는 검토한 파일명과 SHA-256을 고정해 이 캡처들만 예외로 허용합니다. 파일을 교체할 때는 화면과 메타데이터를 다시 검토한 뒤 해당 해시를 갱신해야 합니다. 그 외 이미지·운영 데이터·인증 파일은 계속 차단합니다.
